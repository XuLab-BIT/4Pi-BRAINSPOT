4Pi-BRAINSPOT

A MATLAB toolbox for in situ 4Pi-PSF retrieval, dynamic interferometric correction, and GPU-accelerated 3D single-molecule reconstruction.

Download toolbox Watch results
01 In situ model generation

Retrieves the 4Pi PSF directly from experimental molecular datasets.

02 Dynamic aberration update

Corrects cavity-phase and objective-misalignment changes over time.

03 End-to-end GUI

Guides alignment, segmentation, localization, drift correction, and display.

Built as companion software for the manuscript, 4Pi-BRAINSPOT turns four-channel interferometric recordings into axial color-coded 3D reconstructions while keeping the calibration model anchored to the sample itself.
